EXAMPLE 1: CREATE A RISK
───────────────────────

User: "I want to create a new risk"
     │
     ↓
Frontend: Dashboard opens form
  - Calls: GET /per_mst_business_process → Gets list of processes
  - Calls: GET /impact → Gets impact levels
  - Calls: GET /likelihood → Gets likelihood levels
  - Calls: GET /risk-subcategories → Gets risk types
  - User selects and fills form
     │
     ↓
User: "Save"
     │
     ↓
Frontend: 
  - POST /per_trn_identify_risk {process_id, category_id, ...}
  - Backend receives request
  - Backend proxies to Oracle ORDS
  - Oracle inserts into PER_TRN_IDENTIFY_RISK table
     │
     ↓
Oracle: New risk_id = 126 created ✅
     │
     ↓
Frontend: Success! Risk created
  - Dashboard refreshes
  - Shows new risk in list
     │
     ↓
Dashboard: 
  - Calls: GET /dashboard/summary → Shows updated stats
  - Shows: "26 total risks" (was 25 before)


EXAMPLE 2: VIEW RISK TREND
─────────────────────────

User: "I want to see risk trends"
     │
     ↓
Frontend: Dashboard page loads
  - Calls: GET /dashboard/risk-trend
  - Backend proxies to Oracle
  - Oracle runs: SELECT TRUNC(created_date,'MONTH'), COUNT(*) ...
  - Returns: [
      {month: '2024-03', risk_count: 5, avg_level: 2.3},
      {month: '2024-02', risk_count: 8, avg_level: 2.5},
      ...
    ]
     │
     ↓
Frontend: Renders line chart with trend data ✅


EXAMPLE 3: UPDATE ASSESSMENT
───────────────────────────

User: "I want to update control assessment"
     │
     ↓
Frontend: Assessments page loads
  - Calls: GET /assessments/controls → Shows existing assessments
  - User selects one to edit
     │
     ↓
User: "Change effectiveness rating to EFFECTIVE"
     │
     ↓
Frontend:
  - PUT /assessments/controls/42 {effectiveness_rating: 'EFFECTIVE'}
  - Backend proxies to Oracle
  - Oracle updates ASSESSMENTS_CONTROLS table
     │
     ↓
Oracle: Row 42 updated ✅
     │
     ↓
Frontend: Success! Assessment updated
  - Shows updated rating
  - Dashboard control effectiveness updates
